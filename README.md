# Simple HP and MP Regen

A small  mod for *Gothic 1 Remake*. It is intended to restore 1% of the player's maximum HP and MP each second while the player is outside combat.

## Install

https://steamcommunity.com/sharedfiles/filedetails/?id=3830016489


## Files

- `GothicMod.json` — mod metadata
- `Script/AutoRestore.as` — AngelScript gameplay effect and player-state hook
