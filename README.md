# Simple HP and MP Regen

A small AngelScript mod for *Gothic 1 Remake*. It is intended to restore 1% of the player's maximum HP and MP each second while the player is outside combat.

## Install

Copy the `SassyQueen-SimpleHPandMPregen` folder into the game's `G1R/Mods/` directory, then enable **Simple HP and MP regen** in the game's mod manager.

## Development status

This mod is in development. The current implementation has not yet been confirmed in-game.

## Files

- `GothicMod.json` — mod metadata
- `Script/AutoRestore.as` — AngelScript gameplay effect and player-state hook

## Compatibility

Made for *Gothic 1 Remake*. Tested game version: not yet recorded.
